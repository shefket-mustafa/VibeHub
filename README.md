# VibeHub

VibeHub is a modern social platform built with **Next.js**, **MongoDB Atlas**, and **JWT authentication**.  
It provides users with a seamless way to connect, share, and explore content in real time.

## Features
- 🔒 Secure authentication with **httpOnly JWT cookies**
- ⚡ Built on **Next.js App Router** for performance and scalability
- 📦 **MongoDB Atlas** with Mongoose for flexible data modeling
- 🎨 Responsive, modern UI powered by React and Tailwind CSS
- 🌍 Scalable foundation for community-driven interaction

## Tech Stack
- **Frontend & Backend:** Next.js (App Router)
- **Database:** MongoDB Atlas with Mongoose
- **Authentication:** JWT with httpOnly cookies
- **Styling:** Tailwind CSS
- **Deployment:** Vercel
